# Sistema-Veterinaria-Citas
Trabajo final del curso Técnicas de Programación Orientada a Objetos 2026  Sistema de Gestión de Veterinaria y Citas Problemática: Pérdida de citas de mascotas, falta de historial médico centralizado  e ineficiencia en el registro de dueños y pacientes.  
Solución: aplicación de escritorio para administrar la atención médica,
el agendamiento de citas y el registro de servicios y vacunas.

Módulo principal: Agendamiento de citas
